MORE THAN ACCESSIBILITY

Technology should make the world easier to experience.

PULANOVA brings different ways of interacting with the world into one accessible digital experience.

OUR PURPOSE

Designed for different ways of experiencing life.

Everyone experiences and interacts with the world differently. Some people depend on visual information, some use sound, while others communicate through touch, speech or captions.

PULANOVA brings these different interaction methods together to help people explore information, communicate and access everyday assistance.

Technical information

Application development

  • Python and Flask
  • HTML, CSS and JavaScript
  • SQLAlchemy, SQLite and PostgreSQL

Artificial intelligence and browser technologies

  • TensorFlow.js and COCO-SSD for object detection
  • YAMNet for sound classification
  • Tesseract.js for English and Tamil text recognition
  • Web Speech API and Web Audio API
  • Vibration API and Geolocation API

Hosting and development

  • GitHub for source-code management
  • Render for application hosting
  • Neon PostgreSQL for hosted database storage

Using PULANOVA responsibly

Some features are experimental. AI recognition may be inaccurate or miss important events. Browser and device support may vary. PULANOVA does not replace certified assistive devices, professional guidance, mobility aids or emergency services.
