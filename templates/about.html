ABOUT THE PROJECT

PULANOVA AI

An AI-powered multisensory accessibility and intelligent navigation system for people with visual and hearing difficulties.

Idea

Accessibility first, AI second. No person should depend on a communication method they cannot use, so PULANOVA offers voice, touch, vision and captions together.

Features

  • Voice-first navigation with spoken confirmations and screen-reader support
  • Smart Haptic Alert System with a customisable vibration language
  • Sound Identity System (doorbell, horn, siren, knock, phone, dog, baby, speech)
  • Find My Object, text reading and Indian currency recognition
  • Conversation Bridge for two-way talk with captions and spoken replies
  • Tactile tools: haptic navigation, custom tactile messages, Morse and Braille output
  • Tactile emergency assistance with location and a help card
  • Custom accessibility profiles for people with more than one need

Tools and technology

  • Python, Flask, SQLite
  • HTML, CSS, JavaScript (no framework)
  • TensorFlow.js: COCO-SSD (objects), YAMNet (sounds)
  • Tesseract.js (text reading, English and Tamil)
  • Web Speech API, Web Audio API, Vibration API, Geolocation API

Limitations

Camera, microphone and location need localhost or HTTPS. iPhone Safari does not support web vibration, so PULANOVA shows a visual pulse and plays beeps instead. A phone cannot replace Braille or a certified safety device. Vibration patterns and AI detection must be tested with users and are not guaranteed warnings.
